# 正式版进度看板后续任务卡

本任务卡只规划后续实现，不创建外部账号、数据库、对象存储、Secret、部署或远程推送。每张卡完成后由总控按实际 diff 和可观察验收决定是否标记 `done`。页面视觉方向见 [`VISUAL_DIRECTION.md`](VISUAL_DIRECTION.md)，前端实现不得把装饰当作已接通能力。

## HK-300：公共后端底座

- 目标：实现自建 ID/密码、session cookie、User/Activity/Membership、服务端角色判定、统一错误、幂等基础、AuditEvent 和数据库访问边界。
- 依赖：本设计文档冻结；用户授权托管平台/本地可复现数据库运行方式后才能进入实际落地。
- 允许修改：认证与数据库访问目录、公共服务端类型/校验、对应单测与本地测试配置；具体路径由总控在开工前冻结。
- 禁止修改：现有 `src/app/tools/**` 页面、首页/导航/全局样式、旧本机契约、环境变量命名、迁移以外的部署配置、任何真实外部资源。
- 必须验证：密码不入日志/响应；session 过期/撤销有效；角色来自服务端 Membership；跨活动资源拒绝；审计白名单不含联系方式明文；重复 operationId 稳定返回。
- 交付：本地 commit SHA、迁移/回滚说明、测试命令与结果、未授权的托管依赖清单。未有数据库授权时只能提交可审查的 adapter/契约，不得伪造线上可用。

## HK-301：正式版进度看板服务端

- 目标：实现 Activity 内 Team/Task CRUD、版本号并发控制、邀请加入、轮询快照、附件元数据/私有存储 adapter、下载授权和相关审计。
- 依赖：HK-300 完成并经总控审查；私有对象存储平台和额度需用户另行授权。
- 允许修改：进度看板专用服务端 service、Route Handler/Server Action、schema/迁移、服务端单测和接口测试；附件 adapter 仅允许私有接口与假实现测试。
- 禁止修改：认证底座、首页/导航、全局样式、其他工具、客户端 localStorage 契约、环境变量命名、实际云 bucket/Secret/部署。
- 必须验证：创建活动→邀请→加入→队伍→任务→更新→另一会话轮询；角色越权、跨活动、重复请求、冲突、过期邀请、附件越权和失败态均有稳定错误码；审计范围符合设计。
- 交付：commit SHA、API 示例、数据库约束/迁移说明、可复现本地演示步骤、真实线上边界。

## HK-301-UI：进度看板页面接入

- 目标：将正式版服务端接入页面，显示登录/活动/角色/同步状态，提供加载、空态、冲突、未授权、过期会话、网络失败和附件失败反馈。
- 依赖：HK-301 服务端接口稳定；前端风格参考由用户提供后再冻结视觉改动。
- 允许修改：进度看板页面与其私有组件/样式、对应客户端 API 调用和测试；若需公共导航或共享样式改动，先停并报告总控。
- 禁止修改：公共后端契约、其他工具、旧本机数据迁移、环境变量和部署配置。
- 必须验证：两个独立浏览器登录不同账号；刷新恢复；轮询看到变化；前端不信任/保存角色；重复提交和冲突提示真实；附件下载失败不显示假成功；窄屏基本可用。
- 交付：commit SHA、浏览器演示步骤、截图/录屏仅作辅助证据，不能替代服务端权限测试。

## HK-301-QA：总控正式版验收与状态切换

- 目标：在授权环境做纵向验收，审查迁移、权限、日志、错误态、私有附件和跨设备读取；通过后才把页面文案从“本机演示”调整为正式版能力描述。
- 依赖：HK-300、HK-301、HK-301-UI 均已提交；托管平台、Secret、测试账号和部署由用户单独授权并准备。
- 允许修改：总控批准的集成文档、任务板、进度投影和必要的接入修复；不直接替子任务扩大 write set。
- 禁止修改：未经用户授权的部署、外部账号/数据、远程推送、付费调用或密钥获取。
- 必须验证：两个独立浏览器、角色越权、刷新/轮询、重复请求、并发冲突、附件越权、审计内容、数据库/存储/session 失败态和回滚路径。
- 交付：验收记录、实际环境/版本、通过与未通过项、剩余风险；只有真实线上证据齐全才允许标记正式能力 `done`。

### 任务流

```text
HK-300 公共后端底座
        ↓
HK-301 看板服务端
        ↓
HK-301-UI 页面接入
        ↓
HK-301-QA 总控验收
```

后续队友匹配、投票、签到可以复用 HK-300 的用户/活动/成员/角色/审计/文件契约，但必须另立私有 write set 和业务验收；不得并行修改 HK-300 的公共文件。
