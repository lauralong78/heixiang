## 功能浏览器证据

- 首页在 390×844 模拟设备中无横向溢出；搜索 `GitHub` 仅显示仓库检查器；“现场”分类显示 4 个路线图项目；只有 2 个工具卡片含链接。
- 名片使用中文与长文本填写后实时更新；实际下载 PNG 为 1200×675、649,862 字节；空表单禁止下载；Tab 可到达主要控件。
- GitHub 检查器已验证无效主机与匿名额度耗尽错误。当前网络出口额度耗尽，因此本轮未取得公开仓库成功响应，不能把该路径标记为已实网验证。
- DeepSeek 使用 mock 验证，没有使用真实 Key，也没有产生 API 费用。

## 安全边界

- `DEEPSEEK_API_KEY` 与 `GITHUB_TOKEN` 仅由服务端读取。
- GitHub 访问固定到 `api.github.com`，仅支持公开仓库，禁止重定向和任意主机。
- 仓库正文作为不可信数据，只参与规则匹配，不会被执行。
- DeepSeek 适配层限制输入、输出、超时和响应体大小，错误不返回 Key 或上游正文。
